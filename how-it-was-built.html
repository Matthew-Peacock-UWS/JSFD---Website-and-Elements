How It Was Built

Every scene on this site was written in TypeScript code. None of them were made in the Babylon.js Editor or any other visual editor.

01

Code, Not an Editor

The Babylon.js Editor lets you build a scene by placing objects with the mouse. I didn't use it. Instead, each scene is a TypeScript function that creates everything the player sees: the ground, buildings, lights, materials, characters, sounds and menus.

Working in code meant the same building blocks could be reused across all five elements, and the scenes could be explained line by line in the documentation.

02

How a Scene Comes Together

Each scene follows the same basic idea: a function creates a new Scene, fills it with objects and returns it, and the engine renders it every frame.

  • Shapes: zombies, houses, cars, trees and the bunker are built from boxes, cylinders and spheres made with MeshBuilder, then merged, cloned or instanced.
  • Materials: textures made in GIMP are loaded onto the shapes.
  • World: terrain is generated from a height map, with a skybox, fog and night-time lighting around it.
  • Behaviour: movement, animation, physics and triggers run in code each frame, using keyboard input, Havok physics and action managers.
  • Interface: menus and the HUD are drawn with Babylon GUI.

03

Shared Code

Anything used by more than one element lives in a shared folder: the player, zombies, props, materials, lighting, GUI and audio. Each element only describes its own layout and rules, so later elements build on the earlier ones instead of starting again.

04

Assets

The textures, skybox and height map were made in GIMP, and the music and sound effects in BandLab and ChipTone. The original project files are kept with the site. The only outside asset is the animated player character, which comes from the Babylon.js asset library.

05

From Code to Website

The scenes are tested on Vite's development server. A build step then compiles each element into its own folder, and each element page on this site loads its scene in a frame. The finished site is hosted on GitHub Pages.
