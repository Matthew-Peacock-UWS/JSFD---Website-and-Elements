How It Was Built

Built in Code

None of these scenes were made in the Babylon.js Editor or any other visual editor. Every mesh, light, material, animation and menu is created by TypeScript code, using a set of shared functions that all five elements build on.

See how they were built →
ScenesWritten in TypeScript
ModelsBuilt from primitive shapes
Textures & soundMade in GIMP, BandLab and ChipTone
EditorNone: no Babylon.js Editor
